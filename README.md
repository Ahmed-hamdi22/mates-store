# Mates Store

Couples clothing storefront. Feature 01 provides a localized Next.js foundation only.

## Run locally

```bash
npm install
npm run dev
```

Open `/en` or `/ar`. The root route redirects to the selected locale.

## Checks

```bash
npm run lint
npx tsc --noEmit
npm run build
```

The `/en/admin` and `/ar/admin` pages are structural placeholders. Admin authentication and store management are future features.
